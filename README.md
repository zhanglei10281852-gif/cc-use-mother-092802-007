# 电网韧性投资规划

山地冰崩等灾害会同时损毁道路与输电设施。本后端在年度投资排序中纳入：

- **资产依赖拓扑**：一个变电站失效会连带切断其下游全部避险点（供电方向传播，含成环/悬空引用校验）；
- **风险情景**：各资产失效概率与替代线路/抢通修复天数，支持多情景与情景对比；
- **服务人口**：连带失电避险点的覆盖人口；
- **修复资源**：年度预算与班组工日双重约束，单班组串行施工时间轴；
- **工程前置条件**：后置项目必须等前置项目完工，阻塞原因可解释；
- **权重可调**：人口 / 抢通时间 / 连锁切断三维度加权，每个分数可展开为维度贡献说明；
- **审批冻结**：已审批年度计划冻结全部输入数据与权重（内容哈希 SHA-256），新增资产关系不能倒改旧版本；
- **施工延期重排**：在途项目延期只推迟其下游项目，生成带父版本链接的新草案；
- **审批回退**：撤销最近审批，原样恢复上一个已审批版本。

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/grid_resilience/contracts.py` | 资产、服务点、情景、权重、资源、候选项目、施工进度数据结构 |
| `src/grid_resilience/network.py` | 拓扑构建、下游失电范围、上游串联失电概率、成环/悬空引用校验 |
| `src/grid_resilience/scoring.py` | 三维度可解释韧性评分与排序 |
| `src/grid_resilience/planning.py` | 资源/前置受限的年度编排、阻塞报告、延期重排时间轴 |
| `src/grid_resilience/versioning.py` | 输入快照、内容哈希、草案/审批/作废/回退版本库 |
| `src/grid_resilience/service.py` | 确定性应用服务与 HTTP JSON 接口（标准库，无第三方依赖） |

## HTTP 接口

```
GET  /health
GET  /versions                      版本列表与当前已审批版本
POST /versions                      提交草案（请求体即输入快照）
GET  /versions/{id}                 排序依据、维度贡献、计划、依赖阻塞、哈希
POST /versions/{id}/approve         审批：冻结数据与权重
POST /versions/rollback             审批回退
POST /replan                        带施工进度/新数据重排（默认挂在当前已审批版本下）
POST /compare                       只评分不建版本，用于比较情景与权重
```

所有数值以字符串传输，内部全程 `Decimal`，不经过 `float`；相同输入永远得到相同
`content_hash` 与排序。

启动服务：

```bash
PYTHONPATH=src python -m grid_resilience --port 8080
```

## 评分口径

对每个候选项目、每个风险情景计算：

1. **人口风险收益** = (改造前失电概率 − 改造后) × 连带失电人口；
2. **抢通时间收益** = 失电概率 × 人口 ×（改造前预期抢通天 − 改造后），替代线路修复
   时间通过 `residual_repair_fraction` 纳入；
3. **连锁切断收益** = 失电概率 × 下游连带资产数。

各维度在候选集合内按最大值归一化到 [0, 1]，再乘以规划人员设定的权重求和。
失电概率取上游串联近似 `1 − ∏(1 − p)`。
